# DeepAgent 旅行规划运行的核验依据

核验日期为 2026-10-28，案例为一次武汉到北京两日游任务。

## 材料范围

文章结合作者与 DeepSeek 的聊天，以及作者提供的 LangSmith 运行页面。运行页面需要相应账户权限，未建立公开分享；正文两张截图展示已核对的部分。

## 已核对的记录

- 整次 LangGraph 运行耗时 518.13 秒。
- 地图子任务 map_agent 耗时 371.72 秒，包含内部模型和工具调用，不能算作一次高德接口延迟。
- 汇总子任务 summary_agent 耗时 82.90 秒，调用树包含目录查看、写文件、回读和多轮模型调用。
- 地图任务要求覆盖 6—8 个景点、多个候选车站的接驳、天气和推荐及备选方案。
- maps_text_search 与 maps_search_detail 的返回均出现过 CUQPS_HAS_EXCEEDED_THE_LIMIT。
- POI 搜索返回大量附属地点、照片链接和空字段；天气返回多个日期及重复温度表示。
- 两个 task 同时发出的观察来自作者在聊天中的陈述，本次未重新计算其精确重叠区间；112.84 秒分支属于票务任务，由作者随后确认。

## 结论边界

没有完成所有叶子节点的耗时、重试次数和 token 核算，不能断言限流为唯一瓶颈，也不能认定发生无限重试。文章中的请求控制、结果筛选与域内工作流是待验证建议，未执行改造后的性能对比。
